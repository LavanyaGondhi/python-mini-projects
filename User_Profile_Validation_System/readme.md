# User Profile Validation System

This is a beginner-level Python mini project built while learning Python functions and string manipulation.

## 📌 Description

This project validates user profile information such as name, email, password, and birth year. It also generates a username automatically and displays a formatted user profile.

The program uses multiple functions to keep the code organized and easy to understand.

---

## 🚀 Features

- Clean and format user input
- Validate email addresses
- Validate password strength
- Generate usernames automatically
- Format full names properly
- Display a user profile report
- Check registration status

---

## 🧠 Concepts Used

- Python Functions
- Strings
- String Methods
  - strip()
  - lower()
  - title()
  - split()
  - endswith()
- Loops
- Conditional Statements
- Boolean Logic
- Input Validation
